# Zodiac Orbit Simulator

An interactive tool that shows *why* your zodiac sign changes through the year — and why astrology and astronomy don't always agree.

*[Try it live](https://jtlenny.github.io/zodiac-simulator/)*

## What it does

- Drag the orbit wheel (or use the slider) to move Earth around the Sun across the year
- See the Sun's current zodiac sign update in real time
- Toggle between **Astrology** (the 12 equal 30° slices used in horoscopes) and **Astronomy** (the real, unequal constellation boundaries — including Ophiuchus, the "13th sign" astrology leaves out)
- Wind the precession slider forward or backward thousands of years to see how the sky slowly shifts over time
- Compare the **Zodiac View** (where the Sun sits today) against the **Midnight View** (what's actually overhead at midnight, 180° opposite the Sun)

## Why

The usual explainer images for this never quite made sense to me, so I built something you can actually turn the dial on. Sharing in case it helps someone else too.

## Running it locally

No build step, no dependencies — it's a single HTML file. Clone the repo and open `index.html` in any browser.
